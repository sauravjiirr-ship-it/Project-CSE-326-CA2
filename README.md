# Ride Easy — Vehicle Rental Platform

A responsive student project built with HTML, CSS, and beginner-friendly JavaScript. It follows the supplied RideEasy sample: vehicle search, vehicle cards, date-based booking, rental total, and a confirmation summary.

## Files
- `index.html` — semantic page structure, vehicle listings, and forms
- `style.css` — colors, layout, cards, and responsive design
- `script.js` — vehicle filtering, price calculation, form checks, and demo confirmation

## Run locally
Open `index.html` in a web browser. No installation or build step is needed.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `ride-easy`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then select **Save**.
6. Wait for the website link to appear in the Pages settings.

Replace `[Your Name]` in `index.html` with your name before publishing.

## Viva points
- Semantic HTML elements such as `header`, `nav`, `main`, `section`, `article`, `form`, and `footer` organize the page.
- CSS provides the design, vehicle card grid, hover effects, and mobile layout using media queries.
- JavaScript filters vehicles, selects a vehicle, calculates rental days and total price, validates the form, and displays a demo confirmation.
- The project has no Python or database. Booking information is only shown on the current page and is not saved as a real reservation.
